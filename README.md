# Foxi Builder releases

Finished, installable versions of the Foxi Builder WordPress plugin.

WordPress sites running Foxi Builder check this repository for new versions and show **Update now** on the Plugins page. Nothing needs to be downloaded from here by hand.

To install Foxi on a new site, download `foxi-builder.zip` from the latest release and upload it under **Plugins › Add New › Upload Plugin**.

The source code is kept in a separate private repository.
