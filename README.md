# Foxi Builder — developer notes

Visual page builder for WordPress, built on the block editor. GPL-2.0-or-later.

## Build

```bash
npm install
npm run build        # compiles src/ into build/
npm run starters     # rebuilds starters/panorama/site.json from tools/build-panorama.mjs
npm run icons        # rebuilds the icon library
python3 tools/build-placeholders.py   # regenerates placeholder images
```

The zip you install only needs the PHP, `blocks/`, `build/`, `assets/`, `starters/` and `templates/` folders. `src/` and `tools/` are kept so the plugin can be developed further.

## How it fits together

| Area | Where |
| --- | --- |
| Bootstrap and module registry | `foxi-builder.php`, `includes/Plugin.php` (filter `foxi_modules` adds modules) |
| Blocks | `blocks/<name>/block.json` (attributes, style elements) + `src/blocks/*.js` (editor) + `includes/Render/*.php` (front end). All Foxi blocks render on the server; `save` returns nothing (or only inner blocks), so markup changes never break saved pages. |
| Style engine | Block styles live in `attributes.fx.style[element][device][state]` and compile to scoped CSS (`src/shared/style-engine.js` in the editor, `includes/Style.php` on the site). |
| Brand Kit | `includes/Brand.php`, `src/brand/`, `src/shared/brand-css.js` (CSS variables `--fx-c-*`, `--fx-font-*`, `--fx-fs-*`). |
| Foxi Studio (editor shell) | `src/studio/` — rail, flyout panels (Add, Sections, Templates, Swap, Brand, Page & SEO, Insights). |
| Insights audit | `src/studio/audit.js` (pure functions, reusable for site-wide audits later) + `panels/InsightsPanel.js`. |
| Site parts and layouts | `includes/Parts.php` (header, footer, archive, single, 404), `includes/Templates.php` (when Foxi layouts apply, built-in defaults), `templates/canvas.php`, `templates/site.php`. |
| SEO | `includes/Seo/Seo.php` (meta, robots, canonical, sitemap), `includes/Seo/Schema.php` (JSON-LD). |
| Starters and site kits | `includes/Starters.php` (import/export, section library), `includes/Migrate.php` (copies images and repoints links when importing a kit from another site). The Panorama template is generated by `tools/build-panorama.mjs`; generic library sections live in `tools/library-sections.mjs`. |
| Admin screens | `includes/Admin.php`, `src/admin/`. |
| REST API | `includes/Rest.php` (namespace `foxi/v1`). |

## Roadmap ideas

- Site-wide Insights report on the dashboard (run the audit over every page).
- AI-free "rewrite for SEO" suggestions using the focus keyword.
- More starter sites (cafe, trades, professional services).
- Global reusable sections (edit once, update everywhere).
- Export a site kit as a .zip with media included, for moving sites offline.
- Redirect manager and 404 log.
- Per-page performance tips (image sizes, font count).
